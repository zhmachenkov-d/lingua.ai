# ADR: Re-ticket dispositions may live only in gitignored `_bmad-output/`

Story 1.8’s refactor sweep needed a place to record items left out of the cleanup bundle without opening GitHub issues mid-story. The plan (`story-refactor-sweep-plan.md`) decided **G2**: the Implementation Notes disposition table and `_bmad-output/initiative-mvp/deferred-work.md` are the authoritative re-ticket record for the ticket tree, and neither is required to appear in git (both paths are gitignored under `_bmad-output/`) (commit `5a95383` for the code sweep; disposition text remains in those plan/deferred-work files). The why in the plan: after an intent_gap showed a “git-visible disposition” claim was unmet because the plan itself is ignored, G2 relaxed 2B so tree continuity for agents is enough and PR reviewers are not promised a tracked disposition file.
