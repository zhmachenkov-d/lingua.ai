# competitive research: Phase A D2 competitive landscape

**Decision this research serves:** Deliver D2 competitive analysis (≥8 products) with strengths, weaknesses, borrow/avoid, applicable/not for textbook+Oxford+FSRS Teacher Agent MVP

## Executive summary

**Do this for D2:** Position the MVP in the **white space** none of the nine peers own as a primary story: **learner’s textbook spine + dictionary-in-context + transparent FSRS + teacher-agent feedback** (RU UI). Borrow **LingQ’s input→tap-save loop**, **Anki/RemNote FSRS + ownership**, **Quizlet’s explicit SR**, **Busuu’s CEFR/review tiering**, **ELSA’s dictionary pronunciation**, **Speak’s Learn→Practice→Apply**, and **ChatGPT Study Mode’s upload-bound tutoring** — without copying Duo/Memrise path locks, LingQ free vocab walls, ELSA scoring/billing distrust, or ChatGPT-as-sole grammar authority [1]–[18].

**Nine products (≥8):** Duolingo, Busuu, Memrise, Quizlet, Anki, LingQ, RemNote (specialized SRS), ELSA Speak, ChatGPT tutors (+ Speak.com as named AI-tutor peer).

**Biggest caveats:** Several dollar prices and independent review clusters thin this run (WebSearch often blocked); market-share leadership claims are first-party only; no peer confirmed Russian UI.

## Cross-dimension insights

1. **White space is structural:** Mass apps sell habit/AI chat; LingQ sells input+opaque SRS; Anki sells SRS shell; Speak/ELSA sell speaking — none lead with *your PDF textbook + Oxford + FSRS + teacher remediation* as one product [1][8][12][16].
2. **Borrow a stack, not a clone:** LingQ input UX + Anki FSRS semantics + Speak practice loop + ChatGPT material-bound tutor + ELSA dict pronunciation — each fills one gap in our PRD spine.
3. **Trust failures to design against:** Duo energy, LingQ free walls, ELSA score distrust, ChatGPT hallucination — map to product anti-patterns (honest quality gates, transparent SRS, cite sources, no fake fluency scores).
4. **RU UI is differentiation if real:** No confirmed Russian UI among Speak/ELSA listings this run [18] — matches our C5/learner-facing Russian need as a wedge *if shipped*.
